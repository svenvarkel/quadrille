CSV · XLSX · ODS · one binary

Edit the cell. Keep the file.

Quadrille is a cell editor for tabular files, used by agents through a JSON command line and by people through a terminal UI. It opens gigabyte CSVs without loading them, changes exactly the cells you name, and copies every unedited record byte for byte.

The problem

Your spreadsheet app is editing your data

Open a CSV in a spreadsheet app, fix one cell, save. The app converts every value it thinks it recognizes. Leading zeros vanish, product codes become dates and long IDs lose digits. Quadrille treats every value as text and writes back only what changed.

For agents

A contract, not a screen scrape

Agents call qd like any other CLI and get structured answers back. Every edit reports the value before and after, and nothing is written until you say where.

  • Strings in, strings out

    Every field comes back as a JSON string. Missing fields in ragged rows are null. Reads outside the file fail instead of truncating.

  • Dry run first

    --dry-run returns the exact cell diff without touching disk. Edits without --dry-run or --output are refused.

  • Safe publishing

    Output is written to a temp file, synced, then renamed into place. Other existing files are refused, and a changed source blocks the save.

  • MCP server in development

    The same engine as MCP tools, in the same binary, so an agent can edit while a person watches the grid.

$ qd shipments.csv --read A7:B8
{"range": "A7:B8",
 "rows": [["000422", "94107"],
          ["000423", "94107"]]}
$ qd shipments.csv --set B7 '00123' --dry-run
{"dry_run": true,
 "changes": [{"cell": "B7",
              "before": "94107",
              "after": "00123"}]}
# changes.json: [{"cell":"B7","value":"00123"}, ...]
$ qd shipments.csv --apply changes.json --output fixed.csv
$ qd shipments.csv --sort 'B,-E:n' --read A1:E20

For people

A grid you drive with function keys

When the agent is done, open the file and check its work. The terminal UI shows edited cells in yellow with an underline, so state never depends on color alone. Every text pair in the palette has at least 7:1 contrast. Mouse selection, scrolling and a clickable key bar work in any terminal that reports the mouse.

Ctrl ZUndo the last edit

XLSX and ODS

Patch the workbook. Leave the rest of it alone.

Native saves rewrite only the edited cells inside the original ZIP and XML package. Other sheets, styles, number formats, formulas and unrelated package members stay as they were. Save without changes, or undo everything, and you get a byte-identical copy.

  • Real cell addresses

    Coordinates match the workbook, leading empty rows and columns included.

  • New formulas

    Type =SUM(B2:N2) into an XLSX cell. Excel or LibreOffice calculates it when the file opens.

  • Protected where it matters

    Existing formula, merged and array cells are read-only. Signed workbooks refuse edited saves.

  • CSV export

    Sort any sheet and export the view to CSV from the CLI or the TUI.

Before you trust it

What qd does not do yet

A data tool earns trust by being clear about its edges. These are the current ones.

No formula calculation

Formula cells show cached results. Values can be stale after edits to their inputs.

No row insert or delete

Quadrille edits existing cells. Structural changes are out of scope for now.

UTF-8 only

Other encodings produce an error instead of silent transcoding. The delimiter is set with -d.

512 MiB sort budget

Sorting keeps keys in memory. Disk-backed sorting is not implemented.

Workbook import limits

5 million cells per sheet and 256 MiB uncompressed. CSV has no such limits.

Edited CSV records are requoted

Unedited records are copied byte for byte. Optional quoting inside an edited record may change.
